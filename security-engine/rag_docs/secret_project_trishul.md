title: Project Trishul - Deployment Plan
classification: SECRET
---
Project Trishul is the secure state data exchange that will connect land, revenue and police records.

Phase 1 goes live in 9 districts on 15 January 2027. The primary data centre is in the State Data Centre, with disaster recovery in a second city.

The deployment budget is Rs 312 crore. The system integrator is selected through a limited tender among three empanelled vendors.

Access to this plan is restricted to officers with SECRET clearance.
