title: Cyber Incident Report - Land Records Server
classification: SECRET
---
On 3 September 2026 an unauthorised login was detected on the land records server from an external IP address. The attacker used a compromised service account.

About 12,000 land record entries were accessed. No records were modified. The service account has been disabled and all administrator passwords were rotated.

The vulnerability was an unpatched remote administration interface exposed to the internet. It has been closed.

This report is shared only with the Secretary, the CISO and CERT-In. It must not be disclosed until the investigation is complete.
